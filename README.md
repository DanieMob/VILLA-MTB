# VILLA MTB

##  Ojetivo del proyecto

VILLA MTB es un sitio web dedicado a las rutas de Mountain Bike
y a las experiencias relacionadas con el ciclismo de montaña.

## La Estructura del sitio

- `index.html`: página principal.
- `rutas.html`: información de las rutas.
- `galerias.html`: videos y contenido multimedia enlazado a Youtube.
- `contacto.html`: formulario de contacto para recibir información.
- `style.css`: estilos del sitio.
- `imagenes/`: recursos gráficos utilizados, fotografías.

## Accesibilidad

Se aplicaron diferentes prácticas de accesibilidad:

- Imágenes con atributos `alt` descriptivos.
- Campos del formulario asociados mediante `<label>`.
- Navegación mediante teclado.
- Estados `:focus-visible`.
- Uso de atributos ARIA cuando son necesarios.
- Uso de `aria-current="page"` para identificar la página actual.

## Estructura semántica

Se utilizaron elementos HTML5 como:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

## Diseño responsive

El sitio utiliza CSS responsive mediante `@media`
para adaptarse a diferentes tamaños de pantalla.

## Tecnologías utilizadas

- HTML5
- CSS3
- YouTube
- GitHub
- GitHub Pages
